## 完成的改造

| 改造 | 减少的重复工作 | 保留的功能与成本 |
|---|---|---|
| Live checkpoint | 成功准入 block 从两次 JSON 编码、三次字节解析减为一次编码、一次字节解析；拒绝的 Tool 直接构造保留字段，避免先复制大参数/正文再清空 | Value→DTO 归一化、精确长度和共享预算检查、最终输出编码仍执行；首次拒绝与共享预算淘汰、32 条描述及内容引用语义不变 |
| Attempt 内容绑定 | 完全相同的绑定复用不可变 owner 和长度证书，仅保留最新一组 owner | 每次仍构造并比较当前绑定；路径、位置、来源、revision、readable_end、deferred 变化都会失效，不保留历史缓存链、不修改旧 cut |
| Transcript 提前复用 | 当前 descriptor 的完整字节及来源坐标匹配时复用已有解码正文；内部 response facts 共享，省完整中间对象和 identity fields 的复制 | 每次仍读真实 descriptor 和独立 Tool 证据；公开页仍复制一次正文及所需 process/response 字段，重新装配当前状态；新增元数据纳入既有 32 行、786,432 字节序列化证明预算，该预算不是缓存总堆内存上限 |
| 请求导航 | 新建模板和节点携带构造结果；实际存储字节相同才省去哈希、MessagePack 解码；scalar 写入后的根节点读取同时供路径检查和长度计算使用 | 保留实际 SQL 读取、原生事实及全部路径检查；随后才计算长度，错误优先级不变。触发器改写、INSERT OR IGNORE 碰撞、后续兄弟节点改写和可选来源回滚仍被检测；只保留当前递归证明，没有跨请求的全量缓存 |
| 内容首块同行保存 | 非追加 UTF8/CanonicalJsonV1 的首个 64 KiB 与 frontier 同行；非空小对象两行变一行，N 块大对象 N+1 行变 N 行，省去一份重复键 | 正文完整保留，溢出块从 segment 1 开始；空对象原本已是一行。Live 历史 revision、Tool 原始 JSON、二进制及组合请求来源仍保持各自语义 |
| 内容读写缓冲 | 已有 UTF8 正文直接绑定借用切片；读取借用 SQLite 当前单元，统一写入一个有界输出 Vec；删除重复结构写入器 | SQL、SQLite 内部处理、公开输出复制和 Base64 编码仍存在；JSON/native 最多两个 64 KiB 缓冲，第二个按需分配；正文切片读取阶段，跨首块/溢出块的非空窗口使用两条查询，其他非空窗口一条；来源/frontier 等校验另有 SQL，空窗口可不查询正文 |

Transcript 的 8 行尾部回归证明，在重复读取及无关 Journal 追加后，8 次 descriptor JSON 解码降为 0。单叶请求回归证明，路径及长度合计只读一次实际根节点；该单叶的新建根节点不解码，既有根节点仍解码一次。以上是操作计数，不直接换算成性能百分比。

首块读取绑定**被选中的确切 revision**，pending 使用验证过的当前 revision；不得因另一个 frontier 存在而读取“最新”首块。普通内容窗口最多读取两个有限切片，返回字节合计不超过 64 KiB；该限制不套用到二进制完整块校验或既有 live metadata 路径。原始 Tool JSON 独立存储，即使 frontier 丢失，仍能检测原始证据，不能回退为重编码参数。

SQLite 保持 **WAL/NORMAL**，schema **84→85**，没有兼容解码或迁移。事务边界及持久性没有因本轮削弱。没有实现 source_kind/representation 整数标签替换，不能声称所有存储冗余均已消除。
