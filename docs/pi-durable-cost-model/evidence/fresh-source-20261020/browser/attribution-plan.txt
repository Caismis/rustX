Counter-boundary clarification
Native CSV fields named complete_self_cpu_ms_since_exec and complete_process_write_mib_since_exec refer to the last recorded after_cleanup point. They do not include later evidence JSON construction/emission and OS process exit; no final wait4/rusage was captured by the original controller. Full process-exit wall is recorded separately. Browser Native counters use the same logical-cleanup boundary; Chrome full-exit CPU is unavailable. Keep these limits explicit rather than claiming complete OS-lifetime CPU. No numerical Native result has been changed by this clarification.
