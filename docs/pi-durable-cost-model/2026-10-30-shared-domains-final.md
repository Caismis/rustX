## 最终实现

- 内部快照按域共享不可变 Arc，可变访问仅分离所访问的共享域；seed 捕获不再深复制完整 snapshot 各域，并删除 `encoding_equal` 遍历。其他 cut、binding 和 frontier 字段仍有复制。保留公开 DTO、真实修改和旧 cut。Transcript/Trace 的 envelope 与正文分开；Tool 更新先只读定位所属域，再获取可变引用，避免复制无关域。
- Attempt 的 model/settings/Tool 使用专门的 admission 重放；删除调用方不使用的单项 fit，整个 Attempt 的最终预算计算仍执行。只保留最新一组 source/item owner，不保留历史缓存链；模型 JSON 顺序和浮点 signed zero 仍参与精确失效。
- Live block 首次 prepare 保留原有一次编码、一次解析和 typed normalization，直接把规范化得到的 DTO 移入输出。只有实际规范化结果与输入精确相等，才缓存 `encoded/required` 准入证书；以后用当前共享预算检查并复制当前不可变输入。第一阶段拒绝不改变 eviction 状态；规范化改变值时继续使用真实规范化路径；冷路径预算不足也只准备一次。每次变化 owner 不再先分配又立即丢弃 model/settings 两个 owner。
- 同一连续事务读取阶段复用 canonical ledger 定位；保留实际 frontier、字节、UTF-8、cut、原始 raw 优先级和生命周期检查。小参数 Tool 内部直接取原始字节，删除 Base64 编码后再解码；公开内容 API 仍保留 Base64 输出。不跨写入、触发器或 API 保存位置证明。
- Statistics/Execution 私有 tuple 使用现有 MessagePack codec，原 16 KiB JSON 逻辑准入、Execution 两阶段准入、非有限 timing 的 null 语义不变。读取校验实际结构和逻辑长度，再 typed decode 并验证 EOF，包含未知字段及显式 null。三个私有列的物理上限为 49,152 bytes，以容纳相同逻辑界限内的二进制表示。

以下是具体读取示例的定位次数；优化后次数由回归断言，优化前按原源码路径计数，并未在基线安装计数器重测：descriptor/read 2→1，长 ID descriptor 3→1，block 四表示 9→1（含 deferred metadata 为 11→1），小参数 Tool 分页 8/6→1。128×18 字节增长回归验证每次 miss 仅一次编码/解析、单项 fit 为零、输出保留规范化分配的原指针与容量；这不是对整个 checkpoint 零复制或零遍历的宣称。

SQLite 维持 **WAL/NORMAL**，schema **86**，每轮原有提交边界不因本轮削弱；无旧 schema 迁移或兼容层。最终公开输出、当前来源验证、实际变化域的复制以及独立查询表/索引仍有成本。

### 长尾和内存不能用中位数掩盖

live/short-large pair 1（从 0 编号）候选平均延迟 **19.104 ms**，旧版 **9.669 ms**，该对均值 **+97.575%**；候选 median 为 9.0835 ms，最慢三个测量轮次为 151.644、109.873、25.434 ms。live/short-small pair 1 两版均值也分别达到 34.338 / 34.655 ms，候选有 383.547 ms 单轮，旧版最慢 184.917 ms。这些样本全部保留，没有诊断出足以给所有长尾作因果归属的证据，不能称它们为已经解释掉的噪声。

进一步检查 live/short-large pair 1，第 3、8 个测量轮次（raw turn 66、71）合计占新旧总延迟差的 79.7%；相邻 settled 采样间的 CPU 增量分别为 10、30 ms，并非该轮专属采样。整段窗口 CPU 为 390→430 ms，写入为 32,313,344→32,116,736 bytes；写入峰在相邻轮次的位置也不同。现有记录无法据此确定等待、I/O 或调度中的哪一项造成了长尾。

采样 RSS 为 **15 对下降、57 对上升**，十二格中位均上升（约 0.065%–0.673%）；匿名 PSS 为 37 降、35 升。证书不再保存 live 正文，并不等于全进程峰值内存必然下降。首批的 71 降/1 升写入、47 对 RSS 上升等反例继续留在原报告和独立 archive，终版不覆盖它们。
