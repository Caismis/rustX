The helper/ directory contains original diagnostic code, not upstream OCCT copies. To rebuild with the same existing pinned O3 object tree/toolchain, place helper files in src/, run prepare.py, build.py, then run.mjs and summarize.py. Paths in scripts deliberately record the actual /tmp inputs used. The cases/ directory preserves every final input; the generator also documents the synthetic construction and source fixtures. relink-unified.py records a one-time instrumentation update during the original run; a fresh build.py against the final sources needs no extra relink. Do not use these runtime artifacts as benchmark results.
